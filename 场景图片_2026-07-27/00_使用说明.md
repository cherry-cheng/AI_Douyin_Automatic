## ⚠️ 重要说明

**这一批图片无法由我（AI 助手）自动生成并写入文件夹。** Google Flow 需要在浏览器中登录 Google 账号、交互式操作，没有可被脚本调用的接口，我这边也没有连接图像生成模型。

因此本文件夹提供的是「**可直接粘贴使用的成品提示词**」——每个场景一个文件，已严格按 `场景图片生成规则.md` 改写完毕。你只需把每个文件里代码块中的提示词复制进 Flow，生成后把图片导出回这个文件夹即可。

## 规则落地说明（已应用到全部 7 条提示词）

原提示词偏「史诗级商业主视觉 / Octane 渲染」，与规则要求的「**新闻纪实 / CNN 风格**」冲突。规则明确警告「❌ 过度美化/戏剧化 → 失去新闻真实性」，因此**规则优先**，已对每条提示词做如下改造：

| 规则要求 | 已落地做法 |
| --- | --- |
| 尺寸用于手机端 | 全部改为 **9:16 竖版**，弱化横向构图 |
| 摄影风格：新闻纪实/纪录片/CNN/轻微胶片感 | 每条加入 `documentary news photography, CNN broadcast aesthetic, subtle 35mm film grain, handheld` |
| 色调冷→暖 | 场景1–2 冷色蓝紫 → 场景3 过渡 → 场景4 暖峰 → 场景5–7 暖色收束/希望 |
| 镜头语言：广角/手持/浅景深特写 | 每条含 `handheld, shallow depth of field`；分镜覆盖远景→特写 |
| 人物尽量不露正脸 | 含人物的场景一律 `face turned away / over-the-shoulder / back of head / face obscured` |
| 同一批图用相同风格词 | 见 `通用风格锚点_与负面提示词.md`，且每条提示词内嵌同一组风格锚点 |
| 宁可平淡不可夸张 | 去除 `hyper-vibrant / epic / 8k Octane` 等夸张词，压回写实 |
| 负面提示词 | 每条附 `通用风格锚点_与负面提示词.md` 中的负面词 |

> 保留的英文数字（¥220 BILLION / ¥400 BILLION / +138% / 700 MILLION USERS / MAINSTREAM CONTENT CARRIER）依规则建议保留英文，避免中文出乱码。

## Google Flow 操作步骤

1. 打开 **https://flow.google**，用 Google 账号登录（免费额度即可）。
2. 新建一个项目（Project / Scene），先**设定基础风格 Frame**：
   把 `通用风格锚点_与负面提示词.md` 里的「风格锚点」作为起始帧（Frames → 起始画面）的提示词，先生成一张定调图。这样后续 7 张能保持「同一批图用相同风格词」。
3. 依次为 `01`–`07` 每个场景：
   - 打开对应文件，复制代码块内的**完整提示词**；
   - 在 Flow 中新建一个 Frame，粘贴提示词，生成；
   - 不满意就在原 Frame 上微调（重抽 / 修改局部词），不要跳到新风格；
   - 筛选标准（规则）：剔除**手指崩坏、构图混乱、严重失真、人脸可识别**的图。
4. 导出每张成图，按 `01_行业报告发布` … `07_主流载体` 命名存回本文件夹，即得一组连贯竖版新闻配图。
5. 收尾统一：裁切比例、亮度/对比度、色温（可用 PS / 美图秀秀）。
