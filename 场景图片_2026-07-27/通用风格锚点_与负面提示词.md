# 通用风格锚点 & 负面提示词

> 用于 Google Flow「起始 Frame 定调」+ 贯穿全 7 图的统一风格。每个场景文件已内嵌本风格锚点，此文件作为「同一批图用相同风格词」的基准。

---

## 风格锚点（Style Anchor）

```
documentary news photography, CNN broadcast aesthetic, subtle 35mm film grain, handheld camera, shallow depth of field, cinematic yet authentic and understated, blue-purple tech color grading, realistic, NOT glossy CGI, NOT cartoon
```

## 比例

```
vertical 9:16 aspect ratio, mobile-first composition, avoid wide horizontal layouts
```

## 负面提示词（Negative Prompt）

适用于 SD / Flow 中的负面输入框：

```
text, watermark, signature, low quality, blurry artifacts, distorted faces, identifiable faces, extra fingers, deformed hands, cluttered composition, oversaturated, glossy 3D render, cartoon, anime illustration, epic key art, hyper-vibrant
```

## 使用要点

- **人物：** 一律不露正脸（背面 / 侧后 / 俯拍头顶 / 剪影 / 面部模糊）。
- **色调走向：** 场景1–2 冷色蓝紫（紧张/数据感）→ 场景3 过渡 → 场景4 暖峰（爆发）→ 场景5–7 暖色（收束/希望）。
- **镜头：** 1 远景 → 2/4 特写 → 3/5 中景 → 6/7 大远景，避免七张构图雷同。
- **态度：** 宁可平淡，不可夸张。
