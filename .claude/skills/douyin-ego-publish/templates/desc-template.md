# 抖音描述 / 话题起草模板

> 起草后**先给 Daniel 过目**再填进去。

## 结构公式

```
[1 句钩子：痛点/卖点/反差，带 1 个 emoji]

[1-2 句说明：解释价值或展开]

[1 句 CTA：提问 / 引导评论收藏]

#精准话题1 #精准话题2 #场景话题3 #泛话题4
```

## 话题策略
- **3-5 个**，多了判堆砌、少了少推荐池
- 精准在前、泛在后：`#精准领域` `#细分话题` `#场景` `#大流量`
- **不要**机械堆「#上热门 #涨粉 #求赞」——低质，伤权重
- 1-2 精准 + 1-2 场景 + 0-1 泛

## emoji
- 每 2-3 句 1 个，别刷屏
- 开头钩子配一个情绪 emoji（🔥💡👀✨）

## 例子

**AI 工具类**
```
一个被严重低估的 AI 工具，每天能省 2 小时 🔥

亲测它能自动整理会议纪要、生成周报，准确率比想象中高，重点是免费额度够用。

你们平时用哪个 AI 工具最多？评论区聊聊 👇

#AI工具 #效率神器 #打工人日常 #人工智能
```

**技术教程类**
```
这道面试题 80% 的人第一反应都错 💡

关键不在背答案，而在理解它背后的底层逻辑——一旦想通，同类题全会。

想看我拆解下一道吗？收藏防走丢 ⭐

#程序员 #技术面试 #编程学习 #计算机基础
```

## 适配要点
- 标题（≤55 字，图文实测 ≤20 更稳）：从钩子里提炼最抓人的那一句
- 描述 ≤200 字（含话题），超了先砍说明句
- 视频类描述可更短，图文类可稍长
